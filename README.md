# Bolso Universitário

Aplicação web minimalista para estudantes universitários controlarem despesas diárias rápidas (restaurante universitário, passagens, lanches e impressões). Atividade prática da disciplina Desenvolvimento de Sistemas Web (EECP0036) na UFMA — Prof. Renan Sousa Freire.

## Escopo inicial

- Registro de despesas com descrição e valor em reais.
- Cálculo automático do saldo total gasto.
- Remoção individual de itens da lista.
- Armazenamento local no navegador via localStorage (Trilha C).
